## 🎯 TL;DR

```bash
# 1. Edita .env.local con tus credenciales
# NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=tu_api_key
# NEXT_PUBLIC_FIREBASE_API_KEY=tu_firebase_key

# 2. Instala dependencias
npm install

# 3. Ejecuta
npm run dev

# 4. Abre en navegador
# http://localhost:3000
```

## 🔑 Variables a Configurar

```bash

# Tu Google Maps API Key (obtener en Google Cloud Console)
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=AIzaSy...

# Tus Firebase Credentials (obtener en Firebase Console)
NEXT_PUBLIC_FIREBASE_API_KEY=AIzaSy...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=my-project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=my-project-id
NEXT_PUBLIC_FIREBASE_APP_ID=1:123456789:web:abc...
```
